# 📖 تطبيق حافظ الأحاديث بالتكرار المتباعد (Hadith Spaced Repetition App)

تطبيق ويب تقدمي (PWA) تفاعلي متكامل يهدف إلى مساعدة الطلاب على حفظ وتثبيت **21 حديثاً دراسياً** (من الأربعين النووية) عبر تقنية **التكرار المتباعد (Spaced Repetition)** مع دعم الإشعارات والقراءة الصوتية والعمل دون اتصال بالإنترنت (Offline-First).

---

## ✨ المميزات الرئيسية (Core Features)

### 1. 📚 بنك الأحاديث الـ 21 (Preloaded Hadith Bank)
- محتوى مسبق يضم 21 حديثاً نبوياً مشكولاً بدقة مع ذكر الراوي والمصدر والسند والملاحظات التربوية.
- إمكانية البحث الفوري والتصفية حسب حالة الحفظ (`جديد` / `قيد الحفظ` / `مراجعة` / `محفوظ`).
- إمكانية إعادة تعيين بطاقة أي حديث أو إعادة تعيين الكل بضغطة زر.

### 2. 🧠 خوارزمية التكرار المتباعد (Spaced Repetition - SM-2)
- خوارزمية ذكية تحسب مواعيد المراجعة تلقائياً وتزيد الفاصل الزمني للأحاديث المحفوظة وتقلله للأحاديث الصعبة:
  - 🔁 **من البداية (Again)**: إعادة المراجعة بعد 5 دقائق وتقليل معامل السهولة.
  - 😓 **صعب (Hard)**: زيادة طفيفة بالفاصل الزمني.
  - 👍 **جيد (Good)**: زيادة طبيعية تتضاعف مع التكرار.
  - ⭐ **سهل (Easy)**: قفزة زمنية أطول للأحاديث الراسخة.
- **خيار يدوي مخصص (Custom Interval)**: تحديد وتيرة ثابتة للتنبيهات (مثال: كل 15 دقيقة، كل نصف ساعة، أو كل ساعتين).

### 3. 🔔 نظام التنبيهات والإشعارات في الخلفية (Notifications Engine)
- دعم كامل لإشعارات المتصفح التفاعلية (Rich Push Notifications).
- **وضع أوقات الهدوء (Quiet Hours)**: تحديد فترة مسائية (مثل: من 11:00 م حتى 7:00 ص) لإيقاف الإشعارات أثناء النوم أو الراحة.

### 4. 🔊 القراءة الصوتية باللغة العربية (Text-to-Speech - TTS)
- نطق صوتي تلقائي لنصوص الأحاديث بدقة باللغة العربية.
- إمكانية التحكم في سرعة القراءة (0.5× إلى 1.5×).
- اختيار الصوت العربي المفضل من بين الأصوات المتاحة في النظام.

### 5. 📱 تطبيق PWA وقاعدة بيانات محلية (Offline-First)
- حفظ فوري وغير متزامن للتقدم والإعدادات محلياً عبر `LocalStorage`.
- ملف `manifest.json` و `Service Worker` مدمج لتمكين التثبيت على شاشة الهاتف كأنه تطبيق Native دون الحاجة لمتجر تطبيقات وبدون إنترنت.

### 6. 🎨 تصميم إسلامي حديث ومتجاوب (UI/UX)
- يدعم الوضع الفاتح والوضع الداكن (Light / Dark Theme).
- واجهة عربية كاملة بتنسيق RTL مع خطي `Amiri` للأحاديث و `Tajawal` للواجهة.
- شاشة إنجاز وتشجيع عند إتمام كل جلسة مراجعة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio**: Web Speech API (SpeechSynthesis)
- **Notifications**: Web Notifications API + Service Worker Cache

## 🚀 طريقة التشغيل محلياً (Getting Started)

### المتطلبات الأساسية:
- [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث)
- مدير الحزم `npm`

### خطوات التشغيل:
```bash
# 1. الدخول إلى مجلد المشروع
cd hadith-memorizer

# 2. تثبيت الحزم اللازمة
npm install

# 3. تشغيل وضع التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000/`

### بناء نسخة الإنتاج:
```bash
npm run build
npm run preview
```
